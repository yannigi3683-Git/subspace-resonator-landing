SCHEDULE RUNNER: shows that start and end by themselves

You add a show, give it its music files on the studio PC, and press ARM. At show time the console goes live, plays the files in order, and ends the broadcast when the last one finishes. Nobody needs to be at the PC.

Sound quality: unchangedIt uses the same GO LIVE, file deck and END you use today. Audio code, mixer and restreamer are not touched.
Crowd size: unchangedNo extra connections for listeners. Same 200-listener room as now.
Runs on your PCThe console stays open on the studio PC. Files stay on that PC, never uploaded.
Safe by designNever starts over a show you are DJing, never ends a show it did not start, never cuts a set short.

Host: setting up a show

Do this on the studio PC, the one that will play the show. Files you add on another computer or phone are not there at show time.

  1. Add the show in the SCHEDULE tab

    Title and start time, exactly as today. You can do this part from your phone too.

  2. Give it its files

    Each upcoming show gets a FILES row. Tap it, then ADD FILES (or drag files in). Each file is copied into the console's own storage on this PC, with a progress bar. A file the browser cannot play is refused before copying, and named.

    FILES · none on this PCADD FILES
    FILES · 4 files · 1:58:20 · on this PC

    In the playlist you can drag to reorder (or use up/down buttons), remove a file, and give any file a display name for the neon line.

  3. Choose what the neon line shows

    NEON: TRACK NAMES (default) or SHOW TITLE. Saved with the show.

  4. Read the two warnings, if any

    If the set is longer than the gap to the next show: "Runs 25 min into Goa Classics 1998. That show will start when this one ends." If the browser did not promise to keep the files: "The browser may clear these files if the disk fills up." Normally it reads "Using 812 MB on this PC. Storage is protected."

  5. Press ARM

    A bar at the top of every console tab. ARM has to be a real click: browsers only allow a page to play sound after a person has clicked on it, and that click is what lets the console start sound later with nobody there.

    SCHEDULE RUNNER OFFARM
    Next show in 3 h has files but SCHEDULE RUNNER is offARM
    SCHEDULE RUNNER ARMED · Psy Night Vol. 7 at 22:00 · checks OK 1 min agoDISARM
  6. Walk away

    Leave the console window open and the PC on (see the PC checklist below). Check on it from your phone whenever you like.

Only one console can be armed

If a second tab or another PC tries, it shows:

Armed on another console (PC-STUDIO), seen 40 s ago

Reload means disarmed

Any reload, Chrome restart or PC restart turns SCHEDULE RUNNER off and asks you to sign in again. Your files stay. Sign in, press ARM.

You can still DJ by hand

Manual GO LIVE and END work exactly as today. If you are live when a scheduled show is due, SCHEDULE RUNNER does not start it and reports START FAILED: already live. If you press END or DISARM during an automatic show, it stops managing that show and leaves it to you.

One show or several in a day

Separate broadcasts

Two shows, each with its own files. Show A ends (END, chat log saved), and show B goes live at its own time. Guests see the countdown between them. There is always at least 15 seconds between an END and the next GO LIVE, so the restreamer sees a real new show.

One continuous run

One show holding all the files. They play back to back with the usual crossfade and only the neon line changes. One chat, one chat log.

A set is never cut. If show A runs past show B's start time, B starts as soon as A ends (plus the 15 seconds).

Checking from your phone

Open /radio and sign in as host with the padlock (as you do to moderate). One status line appears at the top. It only reads; arming happens at the PC. Listeners never see it.

SCHEDULE RUNNER · armed on PC-STUDIO · next Psy Night Vol. 7 22:00 · seen 1 min ago

Green: armed and alive.

SCHEDULE RUNNER · armed on PC-STUDIO · last seen 2 h ago

Amber: no heartbeat for over 3 minutes. The PC is probably off, asleep, or the tab was closed.

SCHEDULE RUNNER · MISSED Psy Night Vol. 7 22:00

Red: a start failed or a show was missed. The missed show stays named for 24 hours.

SCHEDULE RUNNER off

Grey: not armed anywhere.

PC checklist before you leave it armed

  • Chrome open on the console, window visible. Not minimised. Leave the screen unlocked and the display on until the tests tell us locking is safe.
  • Windows Sleep set to Never.
  • Windows Update "active hours" cover your show times, so it never restarts the PC mid-show.
  • Chrome Memory Saver: add subspaceresonator.com to "Always keep these sites active".
  • Chrome: allow automatic downloads for the site (chat logs).
  • Restreamer window running, as on every show night.
  • Never log out of Windows (that kills the show, as today). Win+L lock is fine for manual shows.

Rules worth knowing

Files stay on the PC

Copies live in Chrome's private storage on the studio PC. Nothing goes to the internet. Files added on a Vercel test link exist only on that test link, not on the real site.

Test links are real

Vercel test links use the real station. A show added there appears on the real /radio, and a test that goes live is a real broadcast. Tests use shows titled TEST, at hours with no real show within 6 hours.

It cannot take over

It goes live only if the station is off air, and ends only the broadcast it started itself. A manual show is never touched.

Hard stop

Even if the deck gets stuck, the show ends at its start time + total length + any paused time + 2 minutes.
